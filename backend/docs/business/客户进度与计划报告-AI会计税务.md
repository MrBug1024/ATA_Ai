# AI 注册会计师 / 税务师 智能体 —— 计划报告

> 版本：2026-06 ｜ 阶段：**项目初期** ｜ 说明：本报告不涉及技术细节，聚焦"每个阶段做成什么样、当前到哪、价值是什么"。

---

## 一、它是什么、放在哪

**AI 注册会计师 / 税务师**是「人和数据 AI 平台」的又一垂直智能体，面向会计师事务所、**本地化部署**，目标是形成两个能独立承接业务的智能体：

- **AI 注册会计师**：能独立完成审计项目全流程——风险评估 → 底稿编制 → 报告生成 → 归档；
- **AI 税务师**：能独立完成涉税项目——税务咨询 → 涉税鉴证 → 税务合规计划 → 清算申报；
- 承接业务范围：专项审计、常规年审、土地增值税清算、税务咨询、破产清算审计、代理记账等。

**关键起点优势**：本智能体与平台已落地的「不良资产智能体」**同源**，复用同一套经过验证的智能体底座（编排、可追溯、知识检索、报告生成、本地化部署）——**不是从零开始**。

## 二、我们怎么交付：六阶段范式 + 双方分工

交付是一套**循环逼近**客户理想智能体的方法（同平台统一范式）：

```
①基础方案 → ②架构底座 → ③试运行 ⇄ ④业务蒸馏 ⇄ ⑤迭代 ⇄ ⑥陪跑
                           └──────── 循环往复 ────────┘
```

这是一个**"可自主培养"**的智能体——事务所在 ④⑤⑥ 深度参与，自己喂知识、定逻辑、评效果。双方分工清晰：

| 我们（AI 团队） | 事务所（业务方） |
|---|---|
| 基础部署：把系统装好、环境配好、模型跑起来 | 知识输入：把法规、准则、模板、历史项目资料喂进去 |
| 工具提供：知识导入 / 检索 / 微调等操作工具 | 逻辑定义：告诉 AI"遇到这种情况怎么处理"（如重要性水平、抽凭比例） |
| 技术培训：教业务人员独立使用 | 效果评估：判断 AI 输出对不对、好不好 |
| 陪跑支持：训练中遇到问题协助解决 | 持续优化：补资料、调逻辑 |

| 阶段 | 一句话 | 当前状态 |
|---|---|---|
| ① 基础方案 | 对齐目标、业务流程、部署形态 | 🟡 进行中（本地化已定，业务流程待确认） |
| ② 架构底座 | 可编排、可追溯、可持久化、本地化的底座 | ✅ 可复用（平台已验证） |
| ③ 试运行 | 先选一个业务场景跑通，看得见成果 | ⬜ 待启动 |
| ④ 业务蒸馏 | 事务所把审计/税务 know-how 喂进系统 | ⬜ 规划中 |
| ⑤ 迭代 | 持续打磨提质 | ⬜ 规划中 |
| ⑥ 陪跑 | 业务人员验证真实结果 | ⬜ 待启动 |

## 三、逐阶段：目标 / 做成什么样 / 价值

### 阶段① 基础方案
- **目标**：对齐总体目标、确认各业务流程、定部署形态。
- **做成什么样**：明确两个智能体的能力边界与优先级；与审计团队逐项确认业务流程（专项审计/年审/土增清算/税务咨询…）。
- **价值**：方向对齐，避免返工。
- **当前**：🟡 进行中。部署形态已明确为**本地化（数据不出内网）**；各业务流程**待审计专家确认**。

### 阶段② 架构底座
- **目标**：一套能"编排多步骤、记得住上下文、每个结论可追溯、可本地部署"的稳固底座。
- **做成什么样**：复用平台已验证的智能体底座——可把"读数据 → 分析 → 编底稿 → 出报告 → 归档"串成自动流水线，支持本地化部署、权限隔离、全程留痕。
- **价值**：**核心地基已就绪**，本项目省去从零搭建的时间与风险。
- **当前**：✅ 已具备。

### 阶段③ 试运行（看得见的成果）
- **目标**：先选**一个**业务场景跑通，让事务所直接看到产出。
- **做成什么样**：选一个规则清晰、价值高的场景（如专项审计或税务咨询）→ 产出底稿初稿 + 报告初稿 + 数据来源可追溯，支持人工在线复核修改。
- **价值**：眼见为实，以此为靶子进入共建。
- **当前**：⬜ 待启动（待首个场景选定）。

### 阶段④ 业务流程蒸馏（事务所深度参与）
- **目标**：把事务所的审计/税务专业判断，提炼成系统规则。
- **做成什么样**：事务所导入法规/准则/底稿模板/历史项目；定义判断逻辑（重要性水平怎么定、抽凭比例怎么定、土增扣除项口径等）；系统按事务所行文风格出底稿与报告。
- **价值**：AI 越用越像"所里资深会计师/税务师亲手做的"，沉淀成事务所专属的经验资产。
- **当前**：⬜ 规划中。

### 阶段⑤ 迭代
- **目标**：在真实使用中持续补细节、提准确率。
- **做成什么样**：发现 AI 哪里不行 → 补资料 / 调逻辑 → 复测；新旧法规冲突能自动识别提示。
- **价值**：系统稳定向上。
- **当前**：⬜ 规划中。

### 阶段⑥ 陪跑
- **目标**：业务人员用真实项目验证 AI 结果，偏差反哺④⑤。
- **做成什么样**：我们提供陪跑支持，事务所对照真实底稿/报告核验，形成"系统出 → 人核验 → 系统改"闭环。
- **价值**：从"能演示"走到"敢用、好用"。
- **当前**：⬜ 待启动。

## 四、接下来要做的（初期启动项）

### 1. 业务流程确认（前置）
- **目标**：与审计团队逐场景确认标准流程。
- **做成什么样**：把专项审计/年审/土增清算/税务咨询等流程及"AI 该做哪几步"逐一定清。
- **价值**：后续所有蒸馏的依据，确认后才好动手。

### 2. 首个试运行场景跑通
- **目标**：选一个场景端到端打样。
- **做成什么样**：跑通"读账套/资料 → 分析 → 出底稿+报告初稿 → 可追溯 → 人工复核"。
- **价值**：最快让客户看到价值、建立信心。

### 3. 知识管理工具就绪（让业务人员能自主培养）
- **目标**：把"导知识、查溯源、调逻辑、微调"做成业务人员能独立操作的工具。
- **做成什么样**：知识导入简便；检索可定位到原始资料**页码/段落**；增量更新且新旧法规冲突提示；支持学习事务所行文风格。
- **价值**：**不依赖技术人员**，事务所自己养得起这个 AI。

### 4. 两个智能体角色 + 协作
- **目标**：AI 注会、AI 税务师各司其职并能协同。
- **做成什么样**：审计中发现税务问题自动提示税务师；税务合规方案考虑会计处理；可对接政策库/外部数据源（需授权）。
- **价值**：覆盖事务所主营，协同减少漏项。

### 5. 本地化部署 + 权限隔离 + 全程留痕
- **目标**：满足审计保密与合规。
- **做成什么样**：全系统部署在事务所内网、数据不出网；按部门/项目组分权隔离；思考过程、数据来源、修改记录全程留痕，支持版本对比。
- **价值**：合规可追溯，敢在事务所落地。

### 6. 硬件配置与运维方案
- **目标**：给出可落地的部署预算。
- **做成什么样**：详细硬件配置清单 + 预算建议 + 长期运维（升级/故障响应）方案。
- **价值**：客户好做预算决策。

## 五、当前可复用的基础（从平台继承，省时间）

本项目虽处初期，但以下能力可直接从平台/已落地智能体**继承复用**：

- ✅ 智能体编排底座（多步骤自动流水线）
- ✅ 证据可追溯（结论一键点回原始资料页码/段落）
- ✅ 知识检索（RAG 溯源）
- ✅ 报告 / 底稿生成框架（可套事务所模板）
- ✅ 本地化部署 + 权限隔离
- ✅ 全程留痕 / 版本对比

> 意义：核心地基已就绪，本项目主要工作量在**③试运行打样 + ④业务蒸馏（事务所喂知识定逻辑）**，而非从零造系统。

## 六、需与客户共建 / 拍板的事项

1. **各业务场景流程确认**：需审计/税务专家逐场景确认（这是启动蒸馏的前提）。
2. **首个试运行场景选择**：建议从规则清晰、价值高的场景切入。
3. **判断逻辑口径**：重要性水平、抽凭比例、土增扣除项口径等，由事务所定义。
4. **硬件与部署预算**：依据配置清单确定。
5. **排期**：待业务流程确认后给出（本报告暂不锁定具体时间）。

> 注：本项目处初期，时间排期待"业务流程确认 + 首个场景选定"后再细化给出，避免过早锁定。
