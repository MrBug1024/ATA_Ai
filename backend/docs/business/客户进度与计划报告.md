# 不良资产 AI 智能体 —— 进度与计划报告

> 版本：2026-06 ｜ 面向：业务方/客户 ｜ 说明：本报告不涉及技术细节，聚焦"每个阶段做成什么样、当前到哪、价值是什么"。

---

## 一、它是什么、放在哪

**不良资产 AI 智能体**是「人和数据 AI 平台」三大垂直智能体之一（法律 / 建筑工地 / **不良资产**）。在不良资产处置的业务运营框架里，它扮演"AI 大脑"的角色：

- 把不良资产处置的行业经验（估值口径、风险研判、处置策略、司法时效、回款规则）**沉淀进系统**，让机器自动跑；
- 向上承接**众包采集**的尽调数据，向下输出**处置执行指令**，中间完成**估值—审计—策略—回款—复盘**全链路；
- 目标：**降低专业门槛、减少重复人工、标准化输出、可私有化部署**，让"专业的事系统先做一遍，人只做关键判断"。

一句话：**采集（众包）→ AI 审计大脑 → 处置执行 → 回款复盘**，这条闭环里的"大脑 + 自动刷新"就是本智能体。

## 二、我们怎么交付：六阶段范式

交付不是一次性"做完上线"，而是一套**循环逼近**客户理想智能体的方法：

```
①基础方案 → ②架构底座 → ③试运行 ⇄ ④业务蒸馏 ⇄ ⑤迭代 ⇄ ⑥陪跑
                           └──────── 循环往复 ────────┘
```

- **①②** 是地基（一次性夯实）；
- **③④⑤⑥ 循环**：用真实业务不断校正系统（④），与可演示的成果（③）相互验证、持续迭代（⑤），并由运营人员实地陪跑核验（⑥），直到逼近"客户心里那个智能体"。
- **③、④ 阶段客户参与感最强**——客户看着 试运行 提意见、用真实业务策略喂系统，是共建过程。

| 阶段 | 一句话 | 当前状态 |
|---|---|---|
| ① 基础方案 | 对齐要做什么、边界、部署形态 | ✅ 基本完成（部署形态待定） |
| ② 架构底座 | 搭好可编排、可追溯、可持久化的底座 | ✅ 已完成 |
| ③ 试运行 | 出得来报告、报表、看板，客户看得见 | ✅ 已成型（标杆案件端到端跑通） |
| ④ 业务蒸馏 | 把行业 know-how 提炼进系统 | 🟡 进行中（核心已蒸，业务规则继续） |
| ⑤ 迭代 | 持续打磨提质提速 | 🟡 持续中 |
| ⑥ 陪跑 | 运营人员验证真实结果 | ⬜ 待启动 |

## 三、逐阶段：目标 / 做成什么样 / 价值

### 阶段① 基础方案
- **目标**：与客户对齐"要做什么、做到什么边界"，确定部署形态（私有化 / 租用算力）。
- **做成什么样**：明确业务范围与优先级，形成路线图；部署方案二选一。
- **价值**：方向不跑偏，投入有的放矢。
- **当前**：✅ 业务框架与需求已对齐；**部署形态（私有化 vs 租算力）待客户拍板**。

### 阶段② 架构底座
- **目标**：搭一套能"编排多步骤、记得住上下文、每个结论可追溯"的稳固底座。
- **做成什么样**：一套可扩展的智能体编排底座——能把"取数→估值→审计→出报告→督办→复盘"串成自动流水线，长报告与对话分离、会话可持久化、可切换不同大模型、可私有化。
- **价值**：后续所有能力都长在这个底座上，**加新功能快、稳、可控**。
- **当前**：✅ 已完成（不良资产智能体即基于此底座搭建）。

### 阶段③ 试运行（看得见的成果）
- **目标**：让客户**直接看到**系统能产出什么。
- **做成什么样**（已交付的成果）：
  - **八段式审计报告**：资产去毒重估、资金流穿透与"白手套"线索、司法时效预警、重整盘活评估、督办任务、增量回款贡献——一份报告把一个案子讲透；
  - **确定性估值引擎**：回收率 / NPV / 净值由系统按固定口径算死，**金额口径统一（万元/4 位/无千分位）**，不同段落数字一致、不漂移；
  - **证据可追溯**：报告里每个关键结论都能**一键点回原文证据页和高亮位置**，结论有据可查；
  - **回款闭环 + 进度看板**：预期回款 vs 实际回款、回收率、催收/利润提醒一屏看清；
  - **AI 复盘**：项目阶段性"预期 vs 实际"三视角对账 + 差异归因 + 经验建议；
  - **司法时效看板**：红黄绿四级 + 倒计时，到期前自动预警；
  - **权威订正**：人工对系统的修正写入台账、**跨会话永久生效、可追溯"谁何时改了什么"**；
  - **权限与人员标签**：按角色分权、五维人员标签（角色/职称/专长/属地/机构）。
- **价值**：客户**眼见为实**，并以此为靶子提需求，进入共建。
- **当前**：✅ 标杆案件已端到端跑通。

### 阶段④ 业务流程蒸馏（当前重点）
- **目标**：把**真实业务策略**提炼成系统规则，让 AI 的产出越来越像"资深专家亲手做的"。
- **做成什么样**：行业 know-how → 系统口径/规则/字段，反复与 试运行 相互验证、逼近理想。
- **已蒸馏进系统**：估值口径固化、回款闭环规则、案件阶段流程、权威订正机制、人员标签体系。
- **接下来要蒸馏的（见第四节）**：拿包前选包研判、众包尽调数据回填、计酬与众包规则、引荐分成、敏感信息分级。
- **价值**：系统**越用越懂行**，逐步替代重复专业劳动，沉淀成别人拿不走的"私有经验资产"。
- **当前**：🟡 进行中。

### 阶段⑤ 迭代
- **目标**：在真实使用中持续提质、提速、补细节。
- **做成什么样**：报告生成提速、复盘能力增强、权限从单体走向多公司隔离等持续升级。
- **价值**：系统稳定向上，不停在原地。
- **当前**：🟡 持续进行。

### 阶段⑥ 陪跑
- **目标**：运营人员用真实项目**验证系统结果**，把偏差反哺回④⑤。
- **做成什么样**：运营对照真实回款/处置结果核验 AI 产出，形成"系统出→人核验→系统改"的闭环。
- **价值**：从"能演示"走到"敢用、好用、用出钱"。
- **当前**：⬜ 待启动（具备 试运行 与业务规则基础后即可开）。

## 四、接下来要做的（④阶段及之后）

> 整体预估 **1.5–2 个月**完成，详细排期见第五节。

### 1. 拿包前·资产选包智能研判
- **目标**：在收购决策前，系统先把资产包研判一遍。
- **做成什么样**：输入项目案卷 → 输出**全量资产清单 + AI 估值测算 + 选包风险研判 + 收购推荐**，给投委会决策做数据支撑。
- **价值**：拿包更准、更快，把风险挡在收购之前。

### 2. 众包采集 ↔ 报告自动回填
- **目标**：把外部众包尽调采集的数据，自动喂进审计报告。
- **做成什么样**：尽调专员上传的基础信息/资产线索/隐匿线索等，**自动回填到报告的资产清单、风险线索、执行指令**，并触发系统重新测算。
- **价值**：人采集、机器汇编，**外勤一上传，报告自动更新**，全链路实时联动。

### 3. 计酬体系（赛马制度）
- **目标**：把众包计酬规则做进系统，公平、可追溯、自动结算。
- **做成什么样**：**先到先得（上传时间戳确权）+ 自动查重 + 平台审核/争议裁定**；多种计酬标准（基础访谈固定价、线索按**净回款分成**、不动产/煤矿**个案竞价**、客服销售按本金/利息/超额分档）；生成结算台账。
- **价值**：激励众包、压低人力成本，**结果付费、按效计酬**。

### 4. 引荐分成（伯乐·三级阶梯）
- **目标**：用引荐机制扩大众包圈层，激励"伯乐"。
- **做成什么样**：邀请码绑定上下级，**三级阶梯分成（10% / 5% / 2.5%）**，仅对增量任务收入分成、被引荐人完成合格任务才产生，单层人数有上限。
- **价值**：低成本扩张专业人力网络，资源型人才也能创造价值。

### 5. 敏感信息分级与脱敏
- **目标**：保护隐私与商业秘密，满足合规。
- **做成什么样**：敏感线索（白手套/税务/刑事）**仅管理层、风控可见**；众包人员只能看自己提交的；上传**自动脱敏**，全文仅管理层可见。
- **价值**：合规可控，放心引入外部众包。

### 6. 多公司数据隔离（多租户）
- **目标**：一套系统服务多家公司，**彼此数据完全隔离**。
- **做成什么样**：同公司内按角色可见，**不同公司互相看不到**；公司管理员看本公司全部、普通成员看自己负责的项目与历史。
- **价值**：可对外多客户运营 / 私有化交付，**数据安全是底线**。

### 7. 私有化部署 + 授权激活（待部署形态确定后）
- **目标**：支持私有化交付，未授权不可用。
- **做成什么样**：私有化部署兼容自带用户中心，**需授权 key 才能启用**，无 key 不可用。
- **价值**：满足高涉密客户本地化要求，保护交付方权益。

### 8. 陪跑上线
- **目标**：运营人员实地验证，跑通"系统→人核验→系统改"。
- **做成什么样**：选真实项目陪跑，按周校验 AI 产出与真实结果偏差并迭代。
- **价值**：从 试运行 走到生产可用，形成可复制的交付样板。

## 五、时间排期（接下来要做的，预估 1.5–2 个月）

按"**安全底座 → 众包运营层 → 拿包前研判 → 陪跑**"的依赖顺序推进（先把数据隔离、敏感分级这层安全底座做好，才能放心引入外部众包人员）。

| 周次 | 交付内容 | 对应第四节 |
|---|---|---|
| 第 1–2 周 | 多公司数据隔离（多租户）＋ 敏感信息分级与脱敏 | 6、5 |
| 第 3–5 周 | 众包采集↔报告自动回填 ＋ 计酬体系（赛马）＋ 引荐分成（伯乐） | 2、3、4 |
| 第 6–7 周 | 拿包前·资产选包智能研判（＋ 私有化授权，视部署决策） | 1、7 |
| 第 7–8 周 | 陪跑启动 ＋ 持续迭代 | 8 |

**合计 ≈ 6–8 周（约 1.5–2 个月）**，整体预计达到"可陪跑试运营"状态。

> 说明：① 时间为预估、**滚动可调**；② 前置条件——计酬/分成等**业务参数需业务方陆续给定**，私有化授权取决于**部署形态拍板**；③ 各能力上线即可逐项试用，不必等全部完成。
