# 钟山区晨光煤矿PDF解析问题诊断报告

## 问题现象
parse_document接口对《钟山区老鹰山镇晨光煤矿法律尽职调查报告.pdf》分析入库时，结构化数据提取与入库不明了、不全。

## 根本原因

### 1. LLM提取返回空数据
从日志分析，多个文档类别的LLM提取返回了`None`或空字典：
- 财务报表：`字段=None`
- 不动产权证：`字段=None`
- 勘探报告：`字段=None`
- 环评批复：`字段=None`

### 2. 静默失败机制
`doc_parser.py`第880-890行的入库逻辑：
```python
elif isinstance(fields_data, dict) and not fields_data.get("parse_error"):
    logger.info("[DocParser][Step 4/4] 入库[%s]", cat)
    _log_asset_details(cat, fields_data)
    r = _ingest_one(case_id, debtor_id, cat, fields_data)
    ingest_results.append({"category": cat, "result": r})
```

问题：
- 当`fields_data=None`时，`isinstance(fields_data, dict)`为False，直接跳过
- 当`fields_data={}`时，通过检查但`_generic_insert`收到空数据无法写入
- 没有记录LLM原始响应，无法排查提取失败原因

### 3. 可能的LLM提取失败原因

#### 3.1 文档内容不匹配字段定义
该PDF是法律尽职调查报告，可能：
- 没有独立的财务报表章节（只有财务状况描述）
- 没有完整的不动产权证信息（只有权证号引用）
- 没有独立的勘探报告（只有储量引用）
- 没有环评批复原文（只有合规性描述）

#### 3.2 LLM敏感词拦截
`llm_client.py`使用了敏感词脱敏机制，但可能：
- 脱敏后的占位符导致LLM理解偏差
- MiniMax的`output_new_sensitive`拦截返回空响应

#### 3.3 提取Prompt不够鲁棒
`doc_parser.py`第234行的提取规则：
```python
"规则：\n"
"1. 只返回JSON对象，不要解释，不要markdown代码块标记\n"
"2. 找不到的字段不要包含在JSON中，不要编造\n"
```

当文档中没有明确字段时，LLM可能返回空JSON `{}`

## 解决方案

### 方案1：增强日志记录（立即可用）
在`doc_parser.py`的`extract_fields_for_category`函数中添加详细日志：

```python
def extract_fields_for_category(category: str, text: str) -> dict | list | None:
    cfg = DOC_CATEGORIES.get(category)
    if not cfg:
        return None
    system = _build_extraction_prompt(category, cfg["fields"])
    try:
        # 记录输入文本前500字
        logger.info("[提取] 类别=%s | 输入文本前500字=%s", category, text[:500])
        
        result = llm_client.chat_json(system, text, temperature=0.05)
        
        # 记录LLM原始响应
        logger.info("[提取] 类别=%s | LLM响应=%s", category, str(result)[:1000])
        
        if isinstance(result, list):
            return result
        if result.get("parse_error"):
            logger.warning("提取失败[%s]: JSON解析错误 | raw=%s", category, result.get("raw_response", "")[:500])
            return None
        
        # 检查是否为空结果
        if not result or (isinstance(result, dict) and len(result) == 0):
            logger.warning("提取失败[%s]: LLM返回空数据", category)
            return None
            
        return result
    except Exception as e:
        logger.error("提取失败[%s]: LLM异常=%s", category, str(e))
        return None
```

### 方案2：改进提取Prompt（推荐）
修改`_build_extraction_prompt`函数，增加容错性：

```python
def _build_extraction_prompt(category: str, fields: dict) -> str:
    field_lines = "\n".join(f'  - {k}: {v}' for k, v in fields.items())
    return (
        f"你是专业的不良资产数据提取员。从用户提供的文本中提取【{category}】的结构化数据。\n\n"
        f"需提取字段：\n{field_lines}\n\n"
        "规则：\n"
        "1. 只返回JSON对象，不要解释，不要markdown代码块标记\n"
        "2. 找不到的字段不要包含在JSON中，不要编造\n"
        "3. 金额统一为元（数字），日期格式YYYY-MM-DD\n"
        "4. 数组字段返回JSON数组\n"
        "5. 如果文本中有多个报告期（如多年财务报表），返回数组，每个元素是一个报告期的数据\n"
        "6. **重要**：如果文本中只有部分字段的描述性信息（非完整表格），也要尽量提取\n"
        "7. **重要**：如果完全找不到任何相关信息，返回空JSON对象 {}\n"
    )
```

### 方案3：入库逻辑增强（必须）
修改`doc_parser.py`第880行的入库逻辑，明确处理空数据：

```python
for cat, fields_data in extracted.items():
    # 财务报表可能返回数组（多报告期）
    if isinstance(fields_data, list):
        if len(fields_data) == 0:
            logger.warning("[DocParser][Step 4/4] 跳过[%s]: 提取结果为空数组", cat)
            continue
        for idx, item in enumerate(fields_data):
            if isinstance(item, dict) and not item.get("parse_error"):
                if len(item) == 0:
                    logger.warning("[DocParser][Step 4/4] 跳过[%s#%d]: 空字典", cat, idx+1)
                    continue
                logger.info("[DocParser][Step 4/4] 入库[%s#%d/%d]", cat, idx+1, len(fields_data))
                _log_asset_details(cat, item)
                r = _ingest_one(case_id, debtor_id, cat, item)
                ingest_results.append({"category": cat, "result": r})
    elif isinstance(fields_data, dict) and not fields_data.get("parse_error"):
        if len(fields_data) == 0:
            logger.warning("[DocParser][Step 4/4] 跳过[%s]: 提取结果为空字典", cat)
            continue
        logger.info("[DocParser][Step 4/4] 入库[%s]", cat)
        _log_asset_details(cat, fields_data)
        r = _ingest_one(case_id, debtor_id, cat, fields_data)
        ingest_results.append({"category": cat, "result": r})
    elif fields_data is None:
        logger.warning("[DocParser][Step 4/4] 跳过[%s]: 提取返回None", cat)
    else:
        logger.warning("[DocParser][Step 4/4] 跳过[%s]: 未知数据类型=%s", cat, type(fields_data))
```

### 方案4：针对性优化（长期）
对于法律尽职调查报告这类综合性文档：

1. **增加"综合报告"类别**
   - 不强求完整字段，提取关键摘要信息
   - 存入`extra_fields`供后续人工审核

2. **改进分段策略**
   - 识别章节标题（如"三、债务人财务状况"）
   - 将整章内容作为一个段落提取，避免表格被截断

3. **多轮提取**
   - 第一轮：提取明确的结构化数据
   - 第二轮：对空结果的类别，用更宽松的Prompt提取描述性信息

## 诊断脚本

运行以下脚本查看该PDF的详细提取情况：

```python
# _diagnose_extraction.py
import sys
sys.path.insert(0, '.')

from doc_parser import _split_segments, classify_segment, extract_fields_for_category, DOC_CATEGORIES
import logging

logging.basicConfig(level=logging.INFO)

# 读取PDF的markdown文本（假设已通过MinerU转换）
with open('钟山区老鹰山镇晨光煤矿法律尽职调查报告.md', 'r', encoding='utf-8') as f:
    text = f.read()

print(f"文档总长度: {len(text)} 字符\n")

# 分段
segments = _split_segments(text)
print(f"分段数: {len(segments)}\n")

# 分类统计
category_segments = {}
for seg in segments:
    cats = classify_segment(seg["text"], seg.get("context", ""))
    for cat in cats:
        if cat not in category_segments:
            category_segments[cat] = []
        category_segments[cat].append(seg)

print("分类统计:")
for cat, segs in category_segments.items():
    print(f"  {cat}: {len(segs)}段")
print()

# 对每个类别尝试提取
print("=" * 80)
print("提取测试")
print("=" * 80)

for cat in ['财务报表', '不动产权证', '勘探报告', '环评批复']:
    if cat not in category_segments:
        print(f"\n[{cat}] 未分类到任何段落")
        continue
    
    print(f"\n[{cat}] 共{len(category_segments[cat])}段")
    
    # 合并该类别的所有段落
    merged = "\n\n---\n\n".join([s["text"] for s in category_segments[cat]])
    print(f"  合并后长度: {len(merged)} 字符")
    print(f"  前500字: {merged[:500]}")
    
    # 尝试提取
    result = extract_fields_for_category(cat, merged[:10000])  # 限制10000字避免超时
    
    if result is None:
        print(f"  ❌ 提取返回None")
    elif isinstance(result, dict):
        if len(result) == 0:
            print(f"  ⚠️  提取返回空字典")
        elif result.get("parse_error"):
            print(f"  ❌ JSON解析错误: {result.get('raw_response', '')[:200]}")
        else:
            print(f"  ✅ 提取成功，字段数: {len(result)}")
            print(f"  字段: {list(result.keys())}")
    elif isinstance(result, list):
        print(f"  ✅ 提取成功，记录数: {len(result)}")
```

运行方式：
```bash
python _diagnose_extraction.py
```
